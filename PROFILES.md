# PROFILES

Les profils sont stockes dans `Audio-Live.apps.json`.

Un profil contient aujourd'hui :

- plan d'alimentation ;
- applications ;
- services ;
- processus ;
- adaptateurs reseau.

Les options globales de securite sont stockees dans `windowsSecurity`.

Profils cibles :

- Usage normal ;
- Preparation studio ;
- Enregistrement ;
- Mixage ;
- Diffusion ou direct ;
- Maintenance ;
- Profil personnalise.

Les chemins personnels reels restent dans la configuration locale et ne doivent pas devenir des exemples generiques.
