# BENCHMARKS

## Etat actuel

Aucun benchmark media n'est applicable : le projet ne parcourt pas encore de sessions audio ni de fichiers medias.

## Scenarios cibles

- 10 fichiers ;
- 100 fichiers ;
- 1 000 fichiers ;
- 10 000 entrees legeres.

## Mesures cibles

- temps d'inventaire ;
- lecture metadonnees ;
- calcul hashes ;
- memoire maximale ;
- acces disque ;
- reactivite interface ;
- annulation ;
- relance.

## Optimisations cibles

- cache metadonnees ;
- cache hashes ;
- parallelisme limite ;
- pas de blocage interface ;
- pas de lectures inutiles.
