# READINESS SCORE

Nom cible : `Score de preparation de la station`.

Ce score ne mesure pas la qualite audio. Il mesure la conformite du poste au profil choisi.

Categories cibles :

- alimentation et performances ;
- interface et pilote audio ;
- applications necessaires ;
- services necessaires ;
- reseau ;
- peripheriques ;
- notifications et fonctions Windows ;
- processus en arriere-plan ;
- stockage disponible ;
- conformite au profil.

Chaque retrait de points devra indiquer :

- regle ;
- etat attendu ;
- etat detecte ;
- points retires ;
- action proposee ;
- bloquant ou non.
